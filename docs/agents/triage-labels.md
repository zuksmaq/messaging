# Triage Labels

The skills speak in terms of five canonical triage roles. This file
maps those roles to the actual label strings used in this repo's
issue tracker.

1. **`needs-triage`** — label: `needs-triage`. Maintainer needs to
   evaluate this issue.
2. **`needs-info`** — label: `needs-info`. Waiting on reporter for
   more information.
3. **`ready-for-agent`** — label: `ready-for-agent`. Fully specified,
   ready for an AFK agent.
4. **`ready-for-human`** — label: `ready-for-human`. Requires human
   implementation.
5. **`wontfix`** — label: `wontfix`. Will not be actioned.

When a skill mentions a role (e.g. "apply the AFK-ready triage
label"), use the corresponding label string above.

Edit the label strings to match whatever vocabulary you actually use.
